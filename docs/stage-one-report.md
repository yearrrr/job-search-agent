## 排查记录

首次收集测试时，上游 Starlette 使用了 AnyIO 的弃用别名，全局“所有警告视作错误”阻断了收集；调整为项目自身弃用警告视作错误，仍保留上游警告输出。最终唯一警告是 `anyio.abc.BlockingPortal` 别名弃用，不影响本次功能，但未来升级时需要复查。

本机系统临时目录存在访问权限问题，导致最初测试夹具无法创建目录。测试改用项目内唯一的 `.local/pytest` 子目录，未修改系统目录权限。Web 测试中的 Windows asyncio 需要内部回环 socketpair；只为该测试允许回环，并通过故意访问被阻断的外部地址验证保护仍有效。

这些问题均已记录并解决到能够执行测试的程度，不把基础设施错误误报为业务通过。后续还补充了非法嵌套模型输出与不一致结束标记的处理。
