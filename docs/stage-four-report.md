# 阶段四测试记录

日期：2026-09-14。环境：Windows、Python 3.12、项目独立虚拟环境。范围为正式业务图的可靠性、故障恢复、调用预算和资料边界。

## 本阶段改动

- HTTP 429/500/503 按创建任务时保存的配置有限重试，每次请求占用总预算。已保存响应复用；请求结果不确定时停止，不自动重发。
- 同步保存执行检查点，识别已有业务任务的检查点缺失；跨进程锁防止同任务同时执行。恢复不会重置调用次数或把旧答复用于下一道问题。
- 草稿编辑与确认指令同事务提交，第二步失败时一并回滚。事实和材料的业务去重覆盖提交后进程突然退出。
- 非法响应、截断输出和密钥回显保留有效的返回用量；未知用量继续保持未知。读取模型响应时限制大小及持续读取时间。
- 模型调用前后核对引用的事实和 JD 版本；发送前隐藏可识别邮箱与大陆手机号；检查目录链接和工具越权。
- 修复带“虚构测试”前缀的人工回答未形成候选事实的问题，以及存储错误页面反复自动刷新的问题。
- 修复草稿修改依据引用事实 UUID 或唯一八位字母数字缩写时，被数字检查误判为无据新增的问题。

## 故障覆盖

| 场景 | 断言与结果 |
| --- | --- |
| HTTP 400/422、401、402、302、418 | 对应安全错误；不重试；重定向不跟随 |
| HTTP 429/500/503 | 配置额外两次时最多三次尝试；持续故障最终停止 |
| 限流后成功 | 回到真实业务工具循环；失败次数计入预算；已知和未知 Token 分开统计 |
| 超时、连接与读取异常 | 一次尝试后停止；不泄露服务商正文或假密钥 |
| 总预算与旧任务 | 先达到总预算就停止；旧任务不因新配置获得额外重试 |
| 截断、非法 JSON、坏工具参数、异常用量、密钥回显 | 不重复请求；保留可用的用量，非法用量不填零 |
| 大响应与持续慢响应 | 在读取时停止，不先完整接收再检查 |
| 请求已登记后硬退出 | 新进程识别结果未知，次数保持一次 |
| 响应已保存后硬退出 | 新进程复用原响应，初次工具选择不再请求 |
| 429 已登记、重试前硬退出 | 恢复到后续尝试，已失败请求及预算保留 |
| 材料/事实提交后硬退出 | 新进程对账，只有一个材料版本或一次事实确认历史 |
| 并发开始、运行与确认 | 操作 ID 去重；操作系统锁串行；只保存一个版本 |
| 编辑后确认指令写入失败 | 整个事务回滚，原内容和修订不变；同一表单随后可成功提交 |
| 检查点丢失、旧页面、运行期间事实变化 | 停止重跑或拒绝过期操作，不发布过期草稿 |
| JD 注入与越权参数 | 拒绝命令行工具、任意路径及跨资料区参数 |
| Windows junction 越界 | 原件和锁目录拒绝跳出资料根目录，外部测试目录未写入 |
| 联系方式预处理 | 发送消息中的测试邮箱/手机号被隐藏；本地原件和事实不改写 |
| 已知引用与数字 | 已知事实 ID 可以作为说明引用；未知 ID、歧义缩写和无据业绩数字仍拒绝 |

独立子进程直接调用 os._exit，确实退出进程，没有使用同进程对象重建替代。子进程同样禁用网络。
