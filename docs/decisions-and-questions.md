# 待确认事项与默认值

日期：2026-09-13。工程默认值是可调整的设计选择，不等于全部已实现能力，也不等于用户个人偏好。阶段一本地基础及真实 API 连通性已完成，详见[连通性记录](api-connectivity-check.md)。

## 1. 真正阻塞的问题

**当前首次工作没有阻塞问题，无需现在提供简历、JD 或 Key。** 后续阻塞应限定到具体步骤，不能因此停止独立的本地开发。

| 事项 | 实际阻塞的步骤 | 到时需要的材料或动作 | 仍可继续的工作 |
| --- | --- | --- | --- |
| Key 配置问题已解决 | 不再阻塞真实 API 调用 | 用户已在 `.env` 配置，单次非敏感文本验证通过；文件保留 mock 模式，正式真实调用需显式启用 | 继续阶段二本地开发与后续样本准备 |
| 尚未提供真实个人资料 | 真实资料解析验收、个人化材料生成与人工核验 | 一份文字型 PDF，或 UTF-8 文本/Markdown；可先删除联系方式，并由用户确认事实 | 用明确虚构的资料建立与测试流程 |
| 尚未提供真实 JD | 真实岗位全流程验收 | 先一条公司＋岗位名＋完整 JD 即可；来源链接可选，约 10 条样本在评测时逐步收集 | 用虚构 JD 开发；真实连通性使用非敏感短文本 |
| 求职目标、城市等未明确设置 | 依赖这些偏好的结论 | 在档案表单中由用户填写，允许留空 | 其他匹配项继续分析；偏好相关项标为资料不足 |
| 暂无人工参考答案和留出集 | 最终 A05/A06 等效果验收 | 依据原文逐条核验经历、结论与草稿；评测前划分样本 | 完成测试工具、记录格式和演示脚本 |

真实资料进入 DeepSeek 请求前，界面应明确说明发送哪些必要文本。使用另一个付费服务、扩大上传范围或改变核心需求时才新增相应确认；这不作为每个普通开发步骤的审批流程。

## 3. 有限预算的拟定默认值

下表保留首版拟定配置，不构成费用保证。阶段一已经实现配置校验、HTTP 超时/输入输出限制、虚构图调用上限以及单次探测限制；正式任务的持久化总预算、检索片段限制和追问轮数仍待后续。`MAX_RETRIES` 目前仅读取校验，适配器和真实探测没有自动重试。真实费用以接口账单为准。

| 参数 | 拟定默认值 | 计数规则 |
| --- | --- | --- |
| 单次 HTTP 超时 | 60 秒 | 超时终止当前尝试；界面在此前仍可查询当前步骤 |
| 每个逻辑请求额外重试 | 1 次 | 仅超时、暂时性连接失败、429、500/503 等可恢复错误；所有尝试都扣模型请求预算 |
| 每个 Agent 任务模型请求 | 最多 8 次 | 包括失败、重试、非法输出后的重新请求；人工恢复不自动清零 |
| 每个 Agent 任务工具请求 | 最多 12 次 | 每个模型提出的工具调用均计数，包括被拒绝的调用；不能通过一次返回多个调用绕过上限 |
| 每轮缺口追问 | 最多 3 个问题 | 用户可稍后回答；补充轮次受整个任务预算约束 |
| 单次检索返回 | 最多 6 段，每段最多 1,200 字符 | 保留可回查来源；需要更多证据可有限再次检索 |
| 单次请求正文 | 最多 20,000 字符 | 包括系统约束、JD、相关事实、工具历史等；超限需分段、缩减或暂停，不能无提示截断关键要求 |
| 单次生成输出 | 最多 2,048 Token | 输入字符限额不等于 Token 数；过长 JD 按要求分组，不能以输出被截断冒充完整分析 |
| 金额估算 | 未配置价格时显示未知 | 配置价格及生效日期后标为估算；缺用量的请求单独标未知，不计作零成本 |
| 连通性探测 | 1 次短文本请求，无自动重试，输出最多 32 Token | 只验证非敏感文本请求；不读取简历，不等同工具调用和业务验收 |

400/401/402/422 等错误先显示参数、鉴权或余额类原因，不自动反复请求，也不切换到另一服务商。错误码分类依据 [DeepSeek 官方说明](https://api-docs.deepseek.com/quick_start/error_codes/)，具体有限重试策略由本项目定义。

需要增加任务预算时，界面应展示已有消耗并由用户明确操作；失败重试或刷新页面不能暗中创建无限的新预算。具体金额预算偏好可在真实样本评测前补充，不阻塞本地开发。
