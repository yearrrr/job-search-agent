## 已交付

- PDF、PNG/JPG/WEBP、TXT、Markdown 的 LLM 解析入口。PDF 先在隔离进程中转为页面图像，再交给模型理解；新入口不使用旧版标题/行规则生成经历。
- 项目、实习/实践、技能、学历、奖项、论文/专利六类经历，以及基础信息和待归类区。以完整经历保存名称、时间、学校/单位、角色、技术、职责与成果、待核对说明和来源。
- 独立填写简历以外的项目或经历。保存后仍需用户确认，学习笔记不会直接进入个人经历库。
- 逐条修改、确认、排除、批量确认和偏好保存均原地更新；批量确认保存当前编辑，冲突时整批回滚。连续重复保存相同内容不增加事实修订。
- 原件/来源、修改历史、已确认计数以及“下一步：导入岗位”入口。重新解析保留已有记录；有新模型结果时默认收起旧版待确认规则候选，批量操作仅处理可见卡片。
- 解析请求账本、有效响应缓存、受限重试与跨进程互斥。已保存响应可在业务提交失败后复用；结果未落盘的请求不会自动重发。
- 新任务的默认限额：输出 102,400 Token、文本请求 100,000 字符、模型 40 次、工具 60 次。本机 .env 已只修改上述四项，密钥与其余配置保持不变。旧任务继续使用其原预算。

## 体验方式

打开 http://127.0.0.1:8000/documents?corpus=personal，进入已有简历，点击“继续 / 用 LLM 重新解析”。核对模型生成的经历，逐条或批量确认，再进入已确认档案或导入岗位。

也可以在“已确认档案”选择“补充项目 / 经历”，填写不在原简历里的内容。模型解析按钮会明确说明发送范围；浏览页面和确认经历不调用模型。
